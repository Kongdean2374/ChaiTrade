# 行情詳情與交易分工驗證

原完整計劃、安全帳務、資料、A／B隔離、T45及原互動要求全部保留。本工作以實際流程驗收，先建立目前行為的失敗證據，不以編譯或IPA代替。

目前確認的根因：`selectProduct`同時改商品與`tab=2`，因此行情／首頁／目錄的查看動作都變成切交易；圖表焦點與交易選擇共用。`VisibleQuoteScheduler.retry`會清掉來源Retry-After，需保留限流退避並合併手動要求。

修改方向：行情使用自己的逐商品導覽路徑；交易選擇及未送出草稿獨立，帶入完整帳戶／交易所／類別／幣別身份與方向。換商品遇未送出編輯須先讓使用者決定，不能默默覆寫。交易選擇器按市場分類，提供搜尋、自選、最近、交易所／類型／幣別／可交易狀態、結果數、清除及空狀態。三處刷新共用排程與狀態，B只讀本地，不建立網路或額外推時間。

## 流程問題與修改

舊版點行情商品會直接改變交易選擇並切到交易，純瀏覽與下單草稿共用狀態。現在行情有自己的商品詳情導覽；列表點選僅改瀏覽目的地與最近查看，底部仍選行情。股票／加密分類、搜尋、排序、自選及返回位置按市場保存。商品身份始終包含來源、交易所、類型與報價幣別，同代碼不同商品不合併。

詳情中的明確買賣才產生帶商品及方向的交易意圖，先處理未送出草稿，再切交易及呈現表單；這一步不送單。交易頂部可獨立選商品，支援分類、搜尋、自選、最近查看與進階篩選／清除／空狀態。換商品重新產生符合自己規則的欄位與行情需求，不沿用另一商品價格、數量或槓桿。保留的草稿仍恢復原內容；新的限價預填才按目前商品、盤別與價格級距取合法值，不重寫行情或降低核心精度要求。

列表、詳情、交易共用更新狀態、最近成功時間與刷新排程。A 合併重複需求、遵守來源配額及退避，優先可見商品與當前詳情，拒絕舊帳戶或舊選擇回應；失敗保留舊值並顯示失效原因。前景時間隨生命週期持續更新，狀態與成交校驗使用相同時間。B 手動刷新唯讀，不建立網路、不抽新價格、不額外走模擬時間。

## 本輪失敗與處理

- 股票旅程：59.350秒失敗。已實看`BB67DCA6`原圖及`61FA0B84`階層，K線WebView在y736、高330，整個位於固定操作列下方；測試尚未捲到圖表就等WebKit動畫回呼。修正測試先要求圖表完整可見，再保留原10秒繪製斷言，實看圖表後捲回整股選擇器。未移除K線、成交、部位、費稅、唯一委託、日誌等斷言。修正後必須重新通過才可接受。
- 合約旅程：120秒逾時；不是通過。固定平倉入口實看`8E25E09C`可直接操作，兩筆意圖／唯一reduce-only賣出／部位歸零均在107秒前核對；切資產後直到168秒才恢復。`C4FFA53F`診斷顯示主執行緒在RenderBox→Metal編譯器XPC等待`xpcproxy_sim`。保留原完整旅程與120秒，以相同App重跑；不因帳務已完成忽略資產操作失敗。
- SE深色大字體資產／設定：首次launch1.73秒到自動化連線70.03秒，消耗約68秒；失敗診斷時App僅啟動約61秒、主執行緒在正常RunLoop。已實看`C9113D92`資產底部及`FC0B7F5A`可見診斷／完成按鈕，關閉檢查在119.67秒，整例仍逾120。保留失敗，以同一測試重新執行，不預熱App或放寬時間。

本次後續提交只修正測試的真實可見操作與文件，App／Core與1.2.6（9）不變。所有69次UI及核心／T45／實際HTTP／大型封存仍在新提交完整重跑；不能將本表綠燈移作新提交的結果。

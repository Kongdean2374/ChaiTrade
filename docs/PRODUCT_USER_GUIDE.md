# ChaiTrade 使用說明

## 行情瀏覽與模擬交易（新流程驗證中）

點「行情」選股票或加密貨幣，搜尋名稱／代碼後點商品；詳情仍留在行情，可返回保留分類、搜尋、排序與位置。瀏覽不會更換交易草稿。詳情按買進／賣出後，才進交易與下單表單；尚未送單。

直接進「交易」，頂部商品選擇器可搜尋、分市場／商品類別、選自選或最近查看，再展開交易所、類型、幣別與可交易狀態篩選。換商品會重新依該商品規則填表；有未送出修改時可保留原草稿取消切換，或明確放棄後使用新商品。送單前核對帳戶模式、名稱、交易所、幣別、方向、單位及預估費用，再自行確認。所有委託與資金均在本機模擬。

列表、詳情和交易均可刷新。A 保留來源配額與退避；失敗保留最後價格並標示狀態，不以舊價錯誤成交。B 刷新只重讀本機狀態，不額外推進模擬時間。沒有行情權限時仍可瀏覽及查看／撤銷本機委託。


此文件對應產品改版工作分支；尚未通過完整產品驗收。所有資金、委託與成交都是本機模擬，不提供真實下單、入金、出金、錢包或支付。

## 第一次開啟

選擇 A「真實行情」或 B「離線模擬」，確認初始虛擬資金後開始。B 可在首次飛航啟動使用內建真實名稱的股票、ETF、加密貨幣與其他市場商品；價格與新聞仍全部是模擬。A 依來源可用權限顯示真實行情，不以 B 的價格補空缺。

頂部「股票／加密貨幣／其他市場」是瀏覽分類，立即生效、共用目前帳戶。A／B 則是兩個完全獨立的帳戶。切換 A／B：設定 → 模式與帳戶 → 選擇下次啟動模式 → 完整關閉 App 再開啟。回到主畫面或切 Tab 不會換帳戶。

## 找商品、看市場與新聞

- 台積電與 0050：股票首頁常見商品，或行情頁搜尋「2330」「台積電」「0050」。
- BTC、ETH：頂部切換加密貨幣，在首頁常見幣種或行情搜尋 BTC／ETH；現貨與合約分區。
- 更多商品：行情 → 商品目錄，直接按市場、分類與名稱／代碼搜尋，每頁20筆，點選便進入商品頁。A 的「探索更多來源商品」可更新來源身份目錄，只加入自己選取的商品；每個交易所／交易對保持獨立身份。官方身份目錄不代表已取得行情或核驗交易規則。
- 搜尋、分類、排序、自選與瀏覽位置按市場保存；切回另一市場不會帶入前一市場的商品委託。
- 排行依目前可取得且有可靠數據的商品集合計算，畫面會標示範圍，不代表完整交易所排行。缺數據不補亂數。

商品頁依序顯示名稱代碼、報價狀態與更新時間、K 線及成交量、可取得的委買賣／成交資訊、持倉與相關新聞。歷史權限不足但當日日內有資料時，保留真實日內圖並顯示限制。沒有來源資料的分鐘不補假 K 線；參考價不產生假五檔。

A 新聞附來源、時間及原文連結，部分來源需另有授權。B 每則醒目標示「模擬情境，非真實新聞」，詳情含事件身份及作用時間；不要把使用真實公司名稱的模擬情境當公告。B 的時間、新聞及價格不與 A 混用。

## 練習買賣

1. 選市場與商品，先確認報價狀態、更新時間、交易單位及可用餘額。
2. 股票選「買進／賣出」，核對股／張與可賣數量；現貨加密選「買入／賣出」，核對幣數與金額。
3. 選市價或限價，輸入數量。進階區依商品能力提供條件委託、追蹤、OCO、括號與成交條件等。
4. 按「檢查委託」，核對方向、商品、數量、預估費稅及資金，再確認送出。
5. 到「委託」查看等待、部分成交、成交或取消；到「資產」查看持倉、資金與費用。

沒有可靠可成交行情時會顯示連線或權限說明，不能送出錯誤成交。休市收盤資料可供瀏覽，不能冒充即時價格。已存在的部位與帳務仍可查看，本機未結委託可撤銷。

按取消、返回或滑下關閉委託視窗不送出。快速連點必須保持同一次委託身份；目前仍有未通過的小螢幕／重新啟動回歸案例，請見測試紀錄，不能據此文件認定所有互動已通過。

合約另有開多／開空、平倉、槓桿、保證金與風險資訊。交易頁底部會列出目前商品各邊既有部位的「平多／平空（僅減倉）」與持有數量，不必先捲過報價與量能；按下仍先開減倉表單，核對摘要後才送出。詳細風險與逐倉保證金操作保留在持倉卡。第一次可從合約商品的「了解與啟用」閱讀風險並明確確認，或在交易偏好啟用；取消不改設定或資金。關閉合約功能後，既有部位仍可平倉。單向／雙向持倉模式須在沒有相關持倉與未結委託時切換。現股賣出不代表可以直接融券開空；未核驗的契約規則有明確限制。

## 資產、虛擬資金與日誌

資產頁可看總資產、可用／凍結資金、現貨與合約部位、損益、費用與資金曲線。跨幣別若缺有效匯率，估值會標示不完整，不假設 1:1。歷史資金流的投入成本保留當時匯率證據，之後取得匯率不會回填成假歷史收益。

「調整虛擬資金／換匯」只修改本機娛樂帳務；可為練習商品配置相應報價幣別，不會轉移真實金錢。「績效與資金流分析」保留交易與持有費用等影響。完整交易匯出、帳本與底層資料放在「資料工具」。JSON／CSV從一致快照逐筆寫檔，包含歸檔歷史；完整JSON含原日誌圖片與離線交易衝擊，供資料閱讀，不直接當作帳戶恢復格式。完成後分享另存，重啟仍可找到；清除資料分享暫存不刪可還原封存或另一帳戶。資料檔未加密，需要加密還原備份時使用完整封存。進入「帳務、交割與市場事件」可依交割、持有費與股務分類瀏覽完整歷史，每頁20筆；已完成的舊紀錄會歸檔保留，待交割義務不因筆數增加而消失。

「本機交易日誌」可記錄文字、標籤及附加本機圖表截圖。按儲存才保存；取消不新增。截圖草稿與日誌匯出是不同操作，沒有外傳就仍留在本機。

## 行情連線

設定第一層分為模式與帳戶、行情連線、交易偏好、離線模擬、外觀與通知、資料備份／還原、進階診斷。

在「行情連線」選來源，先閱讀市場範圍、Key 與方案需求，再測試連線。Coinbase 公開來源可供目前可取得的交易對；Fugle 台股／期貨、Alpaca 等依實際金鑰和授權提供資料。API Key 只輸入 App 的連線精靈並存 Keychain，不貼聊天室、日誌或 GitHub；備份不包含 Key。

依狀態處理：載入中請等候；未設定 Key 前往連線設定；無權限確認方案；限流依提示稍後重試；斷線檢查網路後重試；休市／延遲／過期資料核對時間；不支援的商品改選來源。來源成功一次不代表已通過持續更新與交易品質驗證。

通知以已取得的行情／本機事件判斷，不承諾 iOS 背景持續看盤。通知目的地會核對 A／B 帳戶；另一帳戶的通知不會自動切換或搬移資金。

## 離線模擬、備份與恢復

B 的種子與時間線可重播；事件作用會影響相關價格、量能及流動性，適用的帳務事件共用事件身份並防止重複處理。補算中暫停新委託，可暫停後從已保存進度繼續；不要以關閉畫面跳過未完成的帳務事件。

既有商品部位不會因真實名稱目錄更新變成另一商品；舊模擬身份仍保留。更新介面不自動清空帳戶、自選或歷史。

「資料備份／還原」的完整檔案封存適合大量歷史及日誌截圖，只保存目前獨立帳戶，可選密碼並查看進度或取消。完成後用分享另存至檔案 App；重啟後回到此頁仍可選取已完成封存。清除分享暫存只移除目前帳戶的已完成分享檔，請先另存需要保留的檔案；另一帳戶、帳戶資料與本機恢復點不受影響。

完整封存逐列查核帳務與附件，再按有界區塊壓縮及加密；目前格式的展開上限16GiB與檔案上限24GiB仍受實際可用空間限制。舊備份格式的32MB壓縮／512MB展開上限保持不變，明顯超量時會先提示使用完整封存，不先把所有圖片載入記憶體。大量資料仍須維持App前景直到完成；目前沒有實體iPhone大檔記憶體或背景完成保證。

可建立、瀏覽及還原目前帳戶的本機恢復點。還原與重設前先保存恢復點，完整驗證帳戶／帳本／附件後才取代資料；取消或驗證失敗保留原帳戶。啟動失敗頁也有完整封存恢復入口。密碼遺失無法還原，API Key不進封存；分享檔案由使用者選擇目的地。

重設目前帳戶在模式與帳戶的獨立入口，有明確警告；不會因切換市場或升級介面自動執行。需要保留資料時先完成並驗證備份。

## 安裝與尚未實測的條件

未簽名 IPA 必須由使用者自行選擇簽署方式，不能直接當成已簽名安裝包，不上架 App Store。只以對應 commit 的 CI artifact 為準；舊版本 IPA 不能當改版成果。

付費行情 Key／授權、區域限制的來源，以及實體 iPhone 上的原 2 秒冷啟動、150ms 回饋、記憶體／電量與系統通知權限尚有外部條件阻擋。模擬器與 macOS 儲存測試不能替代它們。最新通過與失敗結果見 [平台與行情驗證紀錄](PLATFORM_HISTORY_VALIDATION_20261027.md) 及 [產品功能對照](PRODUCT_FEATURE_CROSSWALK.md)。
